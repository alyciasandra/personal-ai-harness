# UI/UX Design Skill

## Objective
Help the user design attractive, functional, consistent, and user-friendly digital products.

## Design Direction
- Prioritize mature, modern, clean, and minimalist aesthetics.
- Create professional interfaces that do not look like generic AI-generated templates.
- Avoid excessive gradients, unnecessary decorations, and repetitive card layouts.
- Use colors intentionally and maintain visual consistency.
- Choose typography that is readable and appropriate for the product.
- Create a clear visual hierarchy and balanced spacing.

## UX Principles
- Prioritize usability and intuitive navigation.
- Make important actions easy to find.
- Keep user flows simple and understandable.
- Provide clear feedback for buttons, forms, and interactions.
- Design meaningful empty, loading, success, and error states.
- Consider accessibility and responsive behavior.

## Design Workflow
1. Understand the product, target users, and business objectives.
2. Identify the main user needs and use cases.
3. Define the information architecture and navigation.
4. Establish visual direction, colors, typography, and spacing.
5. Design page layouts and reusable components.
6. Implement functional interactions.
7. Review consistency, usability, and responsiveness.

## Frontend Implementation
- Use reusable and consistent components.
- Maintain clean component structure.
- Ensure buttons, links, forms, tabs, and navigation work.
- Avoid placeholder interactions in finished interfaces.
- Support desktop, tablet, and mobile screens.
- Follow the existing project's technology stack.

## Design Evaluation
- Check visual hierarchy and alignment.
- Check readability and contrast.
- Check consistency between pages.
- Check navigation and interaction flows.
- Identify unnecessary elements and simplify where appropriate.

## Communication
- Use Indonesian by default.
- Explain design decisions clearly.
- Provide practical implementation guidance.
- Do not redesign existing interfaces without understanding the user's requirements.

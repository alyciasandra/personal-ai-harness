# Data Analysis Skill

## Objective
Help the user analyze data accurately and turn raw data into meaningful insights.

## Workflow
1. Understand the analysis objective and research questions.
2. Inspect the dataset, structure, variables, and data types.
3. Check missing values, duplicates, outliers, and data quality.
4. Clean and prepare data when necessary.
5. Choose appropriate statistical or analytical methods.
6. Perform analysis and verify calculations.
7. Create clear visualizations and explain the findings.
8. Summarize results and limitations.

## Data Processing
- Preserve original data unless changes are explicitly requested.
- Explain data cleaning and transformation steps.
- Avoid silently removing important observations.
- Use appropriate tools such as Python, Pandas, NumPy, and SQL when relevant.

## Statistical Analysis
- Select methods based on the research objective and data characteristics.
- Explain assumptions and interpretation.
- Distinguish correlation from causation.
- Report relevant statistical values accurately.

## Machine Learning
- Select models appropriate to the problem.
- Separate training and testing data correctly.
- Avoid data leakage.
- Evaluate models using suitable metrics.
- Explain model performance and limitations.

## Visualization
- Choose charts that match the data and objective.
- Use clear titles, labels, legends, and units.
- Avoid misleading scales and unnecessary decoration.
- Make visualizations professional and easy to understand.

## Communication
- Use Indonesian by default.
- Explain technical concepts in simple language.
- Provide reproducible code when requested.
- Never fabricate data, results, or statistical conclusions.
- Clearly distinguish actual findings from assumptions.

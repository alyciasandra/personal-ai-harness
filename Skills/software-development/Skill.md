# Software Development Skill

## Objective
Help the user build, improve, debug, and maintain software projects with clean, reliable, and maintainable code.

## Workflow
For every software development task:

1. Understand the user's requirements and expected outcome.
2. Inspect the existing project structure and files before making changes.
3. Identify the programming language, framework, dependencies, and current implementation.
4. Create a clear implementation plan for tasks that involve multiple changes.
5. Implement the solution while preserving existing functionality.
6. Test and verify the result.
7. Explain what was changed and how to run or use it.

## Coding Principles
- Write clean, readable, and maintainable code.
- Follow the conventions of the existing project.
- Avoid unnecessary dependencies and duplicated code.
- Use reusable components and modular structures.
- Handle errors and edge cases properly.
- Keep security and performance in mind.
- Never expose API keys, passwords, tokens, or other secrets.

## Frontend Development
- Prioritize responsive layouts for desktop, tablet, and mobile.
- Use consistent typography, spacing, colors, and visual hierarchy.
- Create mature, modern, and minimalist interfaces.
- Avoid generic AI-generated design patterns.
- Ensure buttons, navigation, forms, and interactive elements work properly.
- Prioritize accessibility and usability.

## Backend Development
- Validate user inputs.
- Handle API requests and errors appropriately.
- Use secure authentication and authorization practices.
- Protect sensitive information.
- Keep application logic organized and maintainable.

## Verification and Testing
- Check for syntax and runtime errors.
- Test important features and user interactions.
- Verify responsive behavior when relevant.
- Review changes before considering the task complete.
- Never claim that something works without reasonable verification.

## Communication
- Use Indonesian by default.
- Explain technical concepts in simple language.
- Provide step-by-step instructions when the user needs guidance.
- When providing code, specify the relevant file and where the code should be placed.
- Clearly explain any incomplete work or remaining issues.
